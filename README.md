# Networkwalks-felixTetteh-BO83-WK2-PM1-PM4-Cybersecurity-project

- This week, i explore the use of Nmap, and foot printing, Reconnaissance & Network scanning using variety of Kali Linux Tools.
The various tools used were
1. Whois - Queries public databases to retrieve registration details, ownership records
2. whatweb - Identifies website technologies, including content management systems
3. nslookup - Queries DNS servers to resolve domain names to IP addresses or perform reverse lookups.
4. curl - Transfers data to or from a server using various network protocols
5. wafw00f - Detects and fingerprints Web Application Firewalls (WAF) protecting a website or target URL.
6. dnsrecon - Conducts comprehensive DNS enumeration to gather host records.
